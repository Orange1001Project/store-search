## 1. 개요

### 1-1. 목적·범위

- 전국 전통시장·골목형상점가 가맹점(약 21만 곳)을 자연어로 찾는 지도 기반 검색 서비스를 만든다.
- 1차: **반응형 웹**(모바일 우선) + 관리자 웹. 앱은 이후(같은 API를 쓴다).
- 범위 밖: 오타 교정, 재정렬 모델, 실시간 LLM, 리뷰·평점, 개인화, 원천에 없는 상세 데이터(이미지·영업시간·전화·메뉴·주차·QR), 결제.

### 1-2. 사용자

| 사용자 | 할 수 있는 일 |
|---|---|
| 비회원 | 검색, 지도·목록, 가게 상세, 길찾기·공유 |
| 회원 | 비회원 기능 + 최근 검색어, 즐겨찾기, 탈퇴 |
| 관리자 | 가맹점 수정·숨김, 주간 갱신, 참조 데이터 관리, 통계·로그 조회, 관리자 계정 관리, 접속 기록 조회 |

### 1-3. 시스템 구성

| 구성 요소 | 역할 | 기술 |
|---|---|---|
| 웹 화면 | 사용자 웹(반응형), 관리자 웹 | React, 네이버 지도 JavaScript API v3 |
| API 서버 | 검색(해석·후보·점수·노출·정렬), 회원, 관리자, 로그 수집 | Spring Boot + JPA |
| 임베딩 추론 서버 | 검색어 문장 → 1024차원 벡터, 주간 갱신 때 가게 벡터 생성 | 별도 서버(bge-m3 미세조정 v1, fp32) |
| DB | 가맹점·벡터·참조 데이터·회원·로그 | PostgreSQL 16 + PostGIS 3.4 + pgvector 0.8 이상 |
| 배치 | 주간 갱신, 확장어 생성, 로그 집계·삭제, 즐겨찾기 정리 | API 서버 내 스케줄러 또는 별도 작업 ⚠(서버 구성 대기) |
| 외부 연동 | 지도, 소셜 로그인 | 네이버 지도(NAVER Cloud Platform Maps), 카카오 로그인, 구글 로그인 |
