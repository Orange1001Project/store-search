# 서비스셋 판정 기준 (2026-10-20)

서비스셋(`data/query/service_queries_v1.csv`)의 (쿼리, 가맹점) 판정 기준이다. **기본은 기존 가이드라인 v1.2**
(`benchmark/storesearch_ko_v1/annotation_guideline.md`)를 따르고, 이 문서는 서비스셋에만 있는 쿼리 유형의 기준을 덧붙인다.
두 문서가 다르면 이 문서를 따른다.

## 1. 점수 — 기존과 같다

| 점수 | 뜻 |
|---|---|
| 3 | 쿼리 의도를 바로 채우는 가맹점 |
| 2 | 의도를 채우지만 핵심이 아니거나 일부만 채움 |
| 1 | 관련은 있지만 찾는 가게는 아님(같은 업종의 대안 등) |
| 0 | 관련 없음 |

2점 이상을 정답으로 센다. 판정자는 어느 시스템이 몇 위로 가져온 가맹점인지 모른다.

## 2. 지역 — 판정하지 않는다

- 판정자는 가맹점의 위치·거리를 보지 않는다. "망원시장 떡집"도 떡집이면 3점이다.
- 지역이 맞는지는 좌표로 자동 처리한다. 판정 대상은 이미 쿼리 가정위치에서 2km 안의 가맹점만이다.
- 그래서 반경을 바꿔도 판정은 다시 하지 않는다. 줄이면 다시 채점만 하고, 늘리면 새로 들어온 가맹점만 판정한다.

## 3. 쿼리 유형별 기준

### B 개별 가맹점 ("왜관 발톱닥터 네일", "광복카센타")

| 경우 | 점수 |
|---|---|
| 찾는 그 가게. 상호가 같으면 지점·띄어쓰기·법인 표기가 달라도 같은 가게로 본다 | 3 |
| 같은 업종의 다른 가게 | 1 |
| 상호 일부만 겹치는 다른 업종 가게, 그 밖 | 0 |

### B 브랜드 ("교촌", "GS25", "텐퍼센트커피")

| 경우 | 점수 |
|---|---|
| 그 브랜드의 지점. 표기가 달라도 같은 브랜드면 3점(지에스25·GS25, 비비큐·BBQ) | 3 |
| 같은 업종의 다른 브랜드(교촌 → 다른 치킨집) | 1 |
| 그 밖 | 0 |

반경 안에 그 브랜드 지점이 여러 곳이면 **전부 3점**이다(가까운 지점만 정답이 아니다 — 거리는 2절대로 판정하지 않는다).

### E 결과 없음 ("코스트코", "신세계", "백화점")

- 이름만 겹치고 그 의도를 채우지 못하는 가게는 **0점**이다(신세계약국, 원일정육백화점, 온천어묵, 샤넬의상실).
- 의도를 일부라도 채우면 다른 쿼리처럼 판정한다(예: "5성급 호텔" → 일반 숙박업소 1점, "스타벅스" → 다른 카페 1점).
- 판정 결과 2점 이상이 나온 E 쿼리는 E가 아니므로, 진행자가 설정 `import.exclude_queries`로 빼거나 A로 옮긴다.

### C 상황 ("집들이 선물", "야식")

- **쿼리 문자열만 보고** 보통 사람이 그 말로 찾을 가게를 기준으로 판정한다. 작성자가 적은 의도(`intent`)는 참고만 한다.
- 해석이 여럿이면 그럴듯한 해석 하나라도 채우면 2점 이상이다("집들이 선물" → 꽃집·와인샵·생활용품점 모두 가능).

### 데이터에 없는 속성 ("단체 예약 가능 식당", "늦게까지 여는", "맛집", "24시", "분위기 좋은")

- 가맹점 데이터에는 영업시간·예약·평판 정보가 없으므로 **속성은 판정하지 않고 업종·상품만 본다**.
  "단체 예약 가능 식당"이면 식당이면 3점, "24시 당구장"이면 당구장이면 3점이다.
- 이런 쿼리에는 `attribute` 표시를 붙여 결과를 따로 집계한다(설정 `judging.attribute_keywords`).

### A 업종, D 지역+업종

- 기존 가이드라인 v1.2와 같다(D는 2절대로 지역을 보지 않으므로 A와 같은 방식).

## 4. 판정 절차

- 판정 대상(pool): 쿼리 가정위치에서 반경 2km 안의 가맹점 가운데 다음을 합친 것이다(`scripts/build_service_pool.py`, 자세한 방법은 `docs/SERVICE_EVAL_METHOD.md`).
  시스템 상위 k개는 1km 안 순위와 2km 안 순위 각각에서 뽑는다. 앵커 사례(정답 없는 쿼리에 앵커 근처 위치를 더한 것)는 앵커 가게도 넣는다.
  - 각 시스템의 상위 k개: v1 bge-m3 mj, bge-m3 zero-shot, char BM25
  - 쿼리 단어가 상호·취급품목에 들어간 가맹점(키워드 후보)
- 판정자는 A·B 두 명이다(2026-10-20). 쿼리의 20%는 둘 다 독립 판정해 일치도를 재고, 나머지 80%는 판정 쌍 수가 비슷하도록
  한 명에게만 준다(설정 `judging.annotators`). 판정자가 쓴 쿼리는 가능하면 다른 사람에게 준다.
- 판정 파일은 `benchmark/service_ko_v1/annotations/<round>/판정_A.xlsx`, `판정_B.xlsx`이다. relevance(0~3)와 uncertain(Y)은 드롭다운이다.
  한 쿼리의 후보가 이어서 나온다(쿼리 순서와 쿼리 안 가맹점 순서는 섞여 있음).
- 반경 1km 안에 정답이 하나도 없는 쿼리는 1km 지표에서 빼고, 그 수를 따로 보고한다.
